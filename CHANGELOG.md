# Changelog

## 1.4.0
- Второй движок сборки FPKG (опционально, third_party `fpkg279`): AC-пакеты (доп. контент с ключом доступа), сборка патча вместе с `.remastered.pkg` за один проход, выбор языков PlayGo.
- Оценка размера пакета: ожидаемый `attributePub` и нужный `kernel.addcontMountLevel` по размеру папки игры, до запуска сборки.
- Список служебных файлов пакета расширен (`pfs-version.dat`, `disc_info.dat`, `ext_info.dat`, `lem_notification.dat`, `param.sfo`, `pronunciation.sig`) и дополнен каталогами (`sce_sys/about`, `sce_suppl`, `sce_sc`, `playgo-languages`) — перенос в сторону теперь работает и для каталогов.

## 1.3.0
- **Бэкпорт / Backport** — новая страница (бэкенд Auto-Backpork, собирается из `third_party\Auto-Backpork-main`): режимы «авто», «понижение SDK + подпись», «fake-signed SELF → ELF»; SDK-пары 1–13 (11–13 экспериментальные); пункт «Бэкпорт…» в меню дампов Библиотеки.
- **Только fake-подпись / Fake-sign only** — встроенный `fself-cli` (`make_fself.py` из ps5-make-fself-recursive, BSD-3): в копию или на месте, проверка места на диске.
- **AMPR** — автодобавление эмулятора и режим «всегда» в «Настройках»; строка про AMPR в «Обзоре» теперь видна всегда; индекс AMPR для чистого exFAT пересоздаётся после упаковки.
- **exFAT** — выбор размера кластера; в сверке образов вкладка «Структура exFAT».
- Предупреждение о папке `decrypted` перед упаковкой.
- Библиотека: названия по языкам, реальный минимум прошивки и предел загрузчика, размер дампов.
- Заметные чекбоксы по всему интерфейсу.
- Python-утилиты (mkpfs, backpork-cli, fself-cli) работают в UTF-8.
- Сборка: новые шаги `[5/6]`, `[6/6]`; `-SkipBackpork`, `-SkipFself`.

## 1.2.0
- Библиотека на данных из образов и пакетов (через `ps5aio-helper` на библиотеках PS5 PKG Tool): роли, группы со сворачиванием, трофеи, Activities/UDS, файлы внутри образа, SELF/ELF, `param.json`.
- Сверка двух образов, поиск дубликатов, переименование по шаблону, экспорт списка (CSV/JSON).
- Обслуживание образов: проверка, ремонт exFAT, AMPR, правка файлов (exFAT/FFPKG), пересборка FFPKG, конвертация.
- Очередь задач с сохранением; проверки перед упаковкой (служебные файлы пакета, AMPR, «чистый PFS» со сжатием).
- Исправлено: `multiprocessing.freeze_support()` в замороженном `mkpfs.exe`.
